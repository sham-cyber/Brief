---
name: Customer search source limits
description: Approved sourcing rules for the Person-only Customer Search.
---

**Rule:** Do not scrape or compile Justdial or IndiaMART listings. Use only public search results with citations unless a directory grants an authorized API or written permission. Show phone numbers and role-based business email addresses only when they are explicitly present in returned source text; do not infer or expose personal contact details.

**Why:** Official terms restrict automated extraction or directory compilation without permission. The user chose free, permitted API sources only, and no qualifying free commercial business-directory API was verified.

**How to apply:** Keep restricted domains excluded from Customer Search. If a directory integration is requested later, confirm its permission and commercial-use terms before adding it.
